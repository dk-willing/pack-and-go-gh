# Models

Mongoose schemas and models live here — one file per entity (e.g. `User.model.ts`).

No models are created yet in this foundation stage. Models are added when
the feature that owns them is implemented (e.g. `User.model.ts` alongside
authentication, `DeliveryRequest.model.ts` alongside the delivery-request
feature). See `docs/architecture.md` for the full list of planned entities.
